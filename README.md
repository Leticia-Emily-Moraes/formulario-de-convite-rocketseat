# Formulário de Convite

Formulário desenvolvido durante a trilha de Fullstack da Rocketseat, para criação de convites digitais de eventos no app Festivite.

## 🔍 Sobre o projeto

O objetivo é praticar HTML semântico e CSS puro na construção de um formulário complexo, trabalhando com:

- Estruturação semântica (`form`, `fieldset`, `legend`, `label`)
- Estilização com variáveis CSS (`:root`)
- Flexbox e Grid para layout
- Customização de inputs nativos (`radio`, `checkbox`, `file`)
- Estados de interação com `:focus-visible`, `:hover`, `:checked` e `:has()`
- Pequenos trechos de JavaScript para os controles que não têm equivalente semântico nativo (toggle de tema, seletor de arquivo e nome do arquivo selecionado)

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript

## 📁 Estrutura do projeto

```
formulario-de-convite-rocketseat/
├── assets/         # Imagens e ícones utilizados na página
├── style/
│   ├── global.css  # Variáveis e reset global
│   └── style.css   # Estilos da página
└── index.html      # Estrutura principal da página
```

## ▶️ Como executar

Basta abrir o arquivo `index.html` em um navegador de sua preferência.
